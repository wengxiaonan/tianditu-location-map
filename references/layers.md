# 天地图图层清单与选择

## 一、两种服务形态

| 形态 | 接口 | 适用 |
|---|---|---|
| **WMTS 瓦片** | `http://t{0..7}.tianditu.gov.cn/{layer}_{proj}/wmts?...` | **出论文图请用这个**：可任意幅面、可精确控制坐标系与范围 |
| 静态图 | `http://api.tianditu.gov.cn/staticimage?center=&width=&height=&zoom=&layers=&tk=` | 快速试看。⚠️ 实测**上限 1024×1024**，超出会被截断 |
| 地理编码 | `http://api.tianditu.gov.cn/geocoder?ds={"keyWord":"…"}&tk=` | 由地名取经纬度（标试点/样点） |

`{proj}` 两种取值：

- `_w` = Web Mercator（EPSG:3857）——**本技能用它**，瓦片金字塔与世界标准一致，`lon2x/lat2y` 直接可用。
- `_c` = 经纬度直投（EPSG:4326），瓦片按等经纬度切分，公式不同，非必要不用。

WMTS 请求模板（已封装在 `TileCache.get()`）：

```
http://t{x%8}.tianditu.gov.cn/{layer}_w/wmts
  ?SERVICE=WMTS&REQUEST=GetTile&VERSION=1.0.0
  &LAYER={layer}&STYLE=default&TILEMATRIXSET=w&FORMAT=tiles
  &TILEMATRIX={z}&TILEROW={y}&TILECOL={x}&tk={密钥}
```

`t0`～`t7` 八个子域轮换用于并发；单线程顺序取图时用 `x % 8` 即可。

## 二、图层对照表

| 代号 | 内容 | 有路网？ | 论文区位图建议 |
|---|---|---|---|
| `ter` | 地形晕渲 | **无** | ✅ **首选底图**，有地形层次、不干扰主题 |
| `cva` | 矢量注记（中文） | **无** | ✅ 与 `ter` 叠加，提供地名 |
| `vec` | 矢量底图 | z≥10 起明显 | ⚠️ 慎用；低层级干净，放大后路网成片 |
| `cta` | 矢量注记（含道路注记） | **有** | ❌ 会出现「G98 环岛高速」等路名 |
| `img` | 影像底图 | 无（但纹理杂） | 视主题；印刷后易发暗 |
| `cia` | 影像注记（英文） | 无 | 与 `img` 搭配 |
| `ibo` | 境界（国界/省界/争议区界线） | — | 可用，但**建议改用自有矢量边界**（见 compliance.md） |

**默认组合**：`["ter", "cva"]`。

## 三、如何判断选中的图层有没有路网

肉眼看不等于可复现。给出一个可量化的启发式（`tianditu.warm_ratio()`）：统计暖色像素
（`r>150 且 60<g<210 且 b<120 且 r-b>55`）占比——道路在天地图上普遍用橙黄/红渲染。

⚠️ **只在「同一区域、同一缩放级别、不同图层组合」之间横向比较才可靠**。
绝对值会随地形色调变化（例如海南岛的地形晕渲本身带黄褐色调，单独看会有万分之几的读数），
所以不要把它当成"路网有无"的绝对判据，而应看组合之间的**相对高低**。

实测参考（海南岛同一范围，z=8）：

| 组合 | 暖色占比 | 结论 |
|---|---|---|
| `ter` | ≈0 | 无路网 |
| `cva` | ≈0 | 无路网 |
| `ter + cva` | ≈0 | **采用** |
| `vec` | ≈0.17%（z8）/ 2.15%（z10） | z10 起路网明显 |
| `cta` | ≈2.77% | 明确含路网 |

`build_locator.py` 每次出图都会打印所用图层的暖色占比，便于留痕。

## 四、缩放级别与幅面

Web Mercator 下每级瓦片世界宽度 = `256 × 2^z` 像素。经纬度跨度对应的像素数为：

```
宽 = (lon1 - lon0) / 360 × 256 × 2^z
```

拿它反推该用哪一级：

| 幅面 | 典型范围 | 建议 z |
|---|---|---|
| 全国（含南海诸岛） | 73–136°E / 3.4–54°N | **5** |
| 省级 | 约 3° 经度跨度 | **8** |
| 市县级 | 约 0.5° | **10–11** |

z 越高图越清晰但瓦片数呈 4 倍增长。z=8、3.2°×2.9° 约需 3×2 张瓦片/图层；
z=5、全国幅约需 8×6 张/图层。

**瓦片会被缓存**在 `cache_dir`（默认 `.tdt_cache`），命名 `{layer}_{z}_{x}_{y}.png`。
重复出图不会重复下载；缓存已热时**不需要密钥**也能出图。

## 五、密钥（tk）

天地图服务需要密钥，在 <https://console.tianditu.com.cn/api/key> 申请。

- 传给脚本的两种方式：配置里写 `"tk": "…"`，或设环境变量 `TDT_TK`。
- **不要**把密钥写进要公开的代码仓库。本技能默认读环境变量。
- 密钥有配额；批量取瓦片时缓存能显著省额度。
